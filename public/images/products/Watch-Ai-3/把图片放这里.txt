产品图片目录约定
================

1. 复制本文件夹，改名为你的产品 ID（必须和 JSON 里的 id 一致）
   例如：W13pro / MA40 / S13

2. 把图片放进该文件夹，建议命名：

   Black.png / Silver.png / …  ← 色款透明底单品抠图（必填至少 1 张，像 Ultra5）
   00-overall.png                ← 可与主色款同一张
   01.webp / 02.webp …           ← 功能拼图、场景、卖点图（详情页用）

3. 【封面规则 — 列表卡 / 首页卡只用 images[0]】

   images[0]  = 透明底单品主图 PNG（干净手表/眼镜，无白底方块、无大字海报、无九宫格）
   images[1+] = 其他色款抠图 → 再放营销拼图 / 场景图

   ❌ 不要把 World Cup 海报、功能九宫格、带大标题的 banner 放第一张
   ✅ 参考：Ultra5Black.png；Watch-Ai-4 用 Black1.png；MA35 用 MA35Black01.png

4. 然后在 data/product-modules/ 里复制 _TEMPLATE.json
   改名为：你的产品ID.json（例如 W13pro.json）
   把里面的 YOUR-PRODUCT-ID 全部换成真实 ID
   填好参数即可

5. 刷新 http://localhost:3000/products 即可看到新产品

注意：
- 封面/色款用透明底 PNG；路径：/images/products/产品ID/文件名.png
- 支持 .webp / .jpg / .png
- 不要改动文件名以 _ 开头的模板文件夹
- Linux/Vercel 区分大小写：Black.png 不要写成 black.png
- 白底原图备份：public/images/_studio-originals-backup/
