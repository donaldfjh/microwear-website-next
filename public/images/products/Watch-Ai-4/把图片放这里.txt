产品图片目录约定
================

1. 复制本文件夹，改名为你的产品 ID（必须和 JSON 里的 id 一致）

2. 图片命名建议：

   Black1.png / Grey.png / Star.png  ← 色款透明底单品抠图（像 Ultra5）
   01.webp … 06.webp                 ← 功能/场景图（详情页轮播）

3. 【封面规则】

   images[0] 必须是透明底单品主图 PNG（例如 Black1.png）
   营销拼图、海报放后面，不要当列表封面

4. JSON 在 data/product-modules/ 对应填写

路径格式：/images/products/产品ID/文件名.png
大小写必须与文件名一致。
白底原图备份可放在 _studio-originals/
